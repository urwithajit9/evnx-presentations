$ evnx vault --help
Manage encrypted vaults

Usage: evnx vault [OPTIONS] <COMMAND>

Commands:
  create   Create a vault
  list     List the vaults you can reach
  delete   Delete a vault and every version in it
  share    Share a vault with another evnx account
  members  List who can reach a vault
  role     Change a member's role
  revoke   Revoke a member's access, rotating the vault key
  help     Print this message or the help of the given subcommand(s)

Options:
      --server <URL>  evnx server to talk to. Overrides EVNX_SERVER and config.toml
  -v, --verbose       Enable verbose output
  -q, --quiet         Suppress non-essential output
      --no-color      Disable colored output
  -h, --help          Print help
  -V, --version       Print version

Full guide: https://www.evnx.dev/guides/commands/vault
