$ evnx add --help
Add environment variables to existing .env files.

Subcommands: • service: Add vars for a service (e.g., postgresql) • framework: Add vars for a framework (e.g., django) • blueprint: Add vars from a stack blueprint • custom: Interactive custom variable addition

Usage: evnx add [OPTIONS] <COMMAND>

Commands:
  service    Add variables for a specific service
  framework  Add variables for a framework
  blueprint  Add variables from a stack blueprint (without overwriting existing)
  custom     Add custom variables interactively
  help       Print this message or the help of the given subcommand(s)

Options:
  -p, --path <PATH>
          Output path (default: current directory)
          
          [default: .]

  -y, --yes
          Skip confirmation prompts

  -v, --verbose
          Enable verbose output

  -q, --quiet
          Suppress non-essential output

      --no-color
          Disable colored output

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Full guide: https://www.evnx.dev/guides/commands/add
