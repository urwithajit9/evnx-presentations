$ evnx spec --help
Declare what each variable is: required, format, secret.

Writes `[vars.*]` into `.evnx.toml` — the contract `.env.example` cannot express. A project with no spec behaves exactly as it does today.

Usage: evnx spec [OPTIONS] <COMMAND>

Commands:
  init  Generate a first spec from this project, or from named components
  help  Print this message or the help of the given subcommand(s)

Options:
  -v, --verbose
          Enable verbose output

  -q, --quiet
          Suppress non-essential output

      --no-color
          Disable colored output

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Full guide: https://www.evnx.dev/guides/commands/spec
