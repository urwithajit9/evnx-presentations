$ evnx auth --help
Manage your evnx cloud account

Usage: evnx auth [OPTIONS] <COMMAND>

Commands:
  register  Create an evnx cloud account
  login     Sign in to evnx cloud
  logout    Sign out of evnx cloud
  token     Manage API tokens for CI/CD
  totp      Manage two-factor authentication
  sessions  List and revoke active sessions
  status    Show your account as the server sees it
  help      Print this message or the help of the given subcommand(s)

Options:
      --server <URL>  evnx server to talk to. Overrides EVNX_SERVER and config.toml
  -v, --verbose       Enable verbose output
  -q, --quiet         Suppress non-essential output
      --no-color      Disable colored output
  -h, --help          Print help
  -V, --version       Print version

Full guide: https://www.evnx.dev/guides/commands/auth
